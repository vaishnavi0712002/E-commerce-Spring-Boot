# E-Commerce Web Application

This is my Java project developed using Spring Boot and MySQL. It is a simple e-commerce website where customers can view products and admins can manage products and categories.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- Hibernate
- MySQL
- HTML, CSS, JSP

## Features
- Admin and Customer Login
- Customer Registration
- View Products
- Manage Products and Categories
- Customer Profile Management

## How to Run
1. Download or clone the project.
2. Configure your MySQL database.
3. Update the database details in `application.properties`.
4. Run the project using:

```bash
mvn spring-boot:run
```

5. Open `http://localhost:8080/` in your browser.

## What I Learned
While working on this project, I learned about Spring Boot, database connectivity, Hibernate, and login authentication using Spring Security.
